# Get Your 1024x1024 PNG Icon

Your icon SVG is ready at `app-icon-1024.svg` with π and ∞ symbols matching your game logo.

## 🚀 Quick Method (Recommended)

**Open the HTML converter in your browser:**

1. Navigate to: `icons/create-png-icon.html`
2. Double-click the file to open it in your default browser
   - OR right-click → "Open With" → Choose your browser (Chrome, Safari, Firefox)
3. Click the **"Download PNG Icon"** button
4. The file will download as `app-icon-1024.png`
5. Move it to the `icons/` folder

## 📋 Alternative Methods

### Method 2: Online Converter
1. Go to https://cloudconvert.com/svg-to-png
2. Upload `icons/app-icon-1024.svg`
3. Set output format to PNG
4. Set size to **1024x1024**
5. Download and save as `icons/app-icon-1024.png`

### Method 3: Using macOS Preview
1. Open `icons/app-icon-1024.svg` in Preview
2. File → Export...
3. Format: PNG
4. Resolution: Set to 1024 x 1024 pixels
5. Save as `app-icon-1024.png` in the `icons/` folder

## ✅ What You'll Get

- **Size:** 1024x1024 pixels
- **Format:** PNG
- **Design:** 
  - Cosmic gradient background (#0a0a1a → #1a1a2e)
  - Large π symbol (cyan/blue gradient: #00f5d4 → #00bbf9)
  - Smaller ∞ symbol (purple: #9b5de5) positioned to the right
  - Subtle star decorations
  - Rounded corners with glow effect
  - Matches your game's logo style perfectly!

## 📱 Next Steps
